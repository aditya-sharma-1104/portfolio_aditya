Welcome to the official portfolio repository for **Aditya Sharma** — a Software Developer and Backend Engineer specializing in full-stack engineering, distributed systems, high-performance web applications, and AI-powered solutions.

This website serves as an interactive showcase presenting Aditya's engineering philosophy, featured projects, career trajectory, verified certifications, technical skill matrix, and professional background.

---

## Vision & Design Philosophy

The portfolio is engineered with a focus on performance, interactivity, and modern software design standards:

- **Cyber-Dark Theme & Glassmorphism**: A clean dark aesthetic layered with translucent glass panels, subtle border glows, and radial background gradients.
- **Fluid Animations**: Scroll-triggered section transitions, staggered typography reveals, 3D tilt effects, and smooth card entrances powered by GSAP and Framer Motion.
- **Interactive User Experience**: Includes a customized reactive cursor tracker, floating social navigation dock, and smooth scroll anchors.
- **Engineering Focus**: Built with modular TypeScript components, clean layout hierarchy, and mobile layout tuning.

## Technical Architecture & Key Technologies

| Technology | Purpose in Portfolio |
| :--- | :--- |
| **Next.js 15 (App Router)** | Core framework providing fast server rendering, client component isolation, and routing. |
| **React 18 & TypeScript** | Strict type safety, clean component hierarchy, and modular state management. |
| **Tailwind CSS & Geist Font** | Utility-first styling system coupled with Vercel's Geist Sans & Mono typography. |
| **GSAP & `@gsap/react`** | High-performance ScrollTrigger animations and timeline orchestration. |
| **Framer Motion** | Physics-based UI transitions and interactive element states. |
| **Radix UI Primitives** | Accessible, unstyled UI primitives for accordions, tooltips, dialogs, and navigation menus. |
| **Lucide Icons** | Minimalist vector iconography across all sections. |
| **Vercel Analytics** | Privacy-friendly performance monitoring and traffic analytics. |

## Responsive & Mobile Optimizations

- Dedicated CSS rules (`mobile-optimizations.css`) ensuring smooth touch controls and overflow handling on mobile devices.
- Adaptive typography scaling and responsive grid re-layouts across all breakpoints.
- Custom cursor intelligently disables on touch-enabled devices for a native mobile experience.
